# Jump Reset V4 - Minecraft 1.8.9

Jump reset estilo Vape V4. Reduz knockback sem causar lagback.

## Comandos

| Comando | Descrição |
|---|---|
| `/jumpreset` | Liga/Desliga |
| `/jumpreset on` | Ativa |
| `/jumpreset off` | Desativa |
| `/jumpreset strength <0-100>` | Força da redução do KB |
| `/jumpreset chance <0-100>` | Chance de ativar por hit |

## Config Recomendada

| Servidor | Strength | Chance |
|---|---|---|
| Hypixel | 60-70% | 70-80% |
| Minemen | 75-85% | 80-85% |
| Sem AC | 90-95% | 95% |
